덕친소 운영 방안 순서도

앱이 출시된 뒤 매일·매주 돌아가는 다섯 가지 운영 흐름입니다. 각 단계에는 누가 처리하는지(자동·운영자·사용자)와 쓰는 툴을 표시했습니다.

자동(시스템) 운영자 사용자 판단(분기)
운영 순환
  1. A. 공연 데이터매일 · 수집→검수→게시
  2. B. 사용자 이용상시 · 탐색→예매·매칭
  3. C. 커뮤니티 안전상시 · 필터→신고→제재
  4. D. 업데이트·출시수시 · PR→배포→스토어
  5. E. 지표 리뷰주 1회 · 지표→개선 과제

E에서 나온 개선 과제는 D(업데이트·출시)로, 데이터 보강 과제는 A(공연 데이터)로 돌아가 다음 주기를 시작합니다.
