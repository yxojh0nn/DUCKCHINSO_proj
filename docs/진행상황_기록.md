## 4. 사용자 확인이 필요한 사항

1. **GitHub 푸시**: 프로젝트 폴더 안에 `DUCKCHINSO_proj/` 폴더(원격 `https://github.com/Yeojh3261/DUCKCHINSO_proj.git`)가 새로 생겼다. 이 저장소가 푸시 대상이 맞는지 알려 주면 연결한다. 로그인 창이 뜨면 직접 처리해야 한다. 이 폴더는 건드리지 않았다.
2. **기존 `DuckChinSO/` 폴더**: 다른 프로젝트(Unreal)로 보이며 `.git/info/exclude`로 제외해 두었다. 프로젝트 밖으로 옮기는 것을 권장한다.
3. **사용량**: arena는 호출당 토큰이 크다(해법 1건당 약 20만 토큰). 한도에 다시 걸리면 중단되므로, 한도 해제 후 이어서 진행한다.
