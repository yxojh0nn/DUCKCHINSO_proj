- 후보 해법의 원문은 `.arena/run-20261103-192536-s323876/r0/`, 공격 원문은 같은 폴더의 `r1/`에 있다.

## A. 거의 모든 해법에 공통으로 걸린 문제

### A1. "같이 갈 사람 N명" 숫자와 실제 목록이 다름 (높음)
- 걸린 해법: a001, a002, a003, a004, a005, a006, a007, a008, a009, a010 (10개 중 10개)
- 증상: 공연 상세에서 "같은 아티스트 팬 N명"이라고 보여 주는 숫자와, 눌러서 열리는 매칭 목록의 인원이 다르다. 목록이 비어 버리는 경우도 있다.
- 원인(추정): 숫자는 공연 아티스트 기준으로 세는데, 매칭 목록은 내 관심 아티스트와의 겹침(자카드 점수)으로 걸러서 보여 준다. 내 아티스트와 겹치지 않으면 0%로 나오거나 제외된다.
- 고칠 방향: 숫자와 목록이 같은 함수로 같은 사람을 세게 한다. 목록이 비면 이유를 알려 주는 빈 화면을 둔다.

### A2. 동의 내역이 틀린 내용을 보여 줌 (높음)
- 걸린 해법: a003, a004, a006, a008, a009, a002, a007 (7개)
- 증상: 내 정보에 선택 동의(푸시·광고·야간 광고)를 끄고 켜는 스위치를 넣었지만, 변경한 날짜와 내용을 저장하지 않는다. "동의 내역" 화면은 고정 문구이거나 현재 상태와 어긋난다. "항목별 동의 날짜를 보여 준다"는 문구는 실제로 저장되지 않은 값을 약속한다.
- 법적 관련: 광고성 정보 수신 동의는 기록과 통지가 필요하다(기획서 9장).
- 고칠 방향: 동의 변경마다 항목·값·시각을 상태에 남기고, 동의 내역 화면이 그 기록을 읽게 한다.

### A3. 공유 링크가 앱에서 쓸 수 없는 주소 (중간)
- 걸린 해법: a003, a004, a005, a007, a010 (5개)
- 증상: 공유 링크를 `location.origin`/`window.location.href`로 만든다. Capacitor 앱 안에서는 localhost 주소가 되어 받는 사람이 열 수 없다. 받는 사람에게 해당 공연을 바로 열어 주지 못한다는 지적도 있다.
- 고칠 방향: 배포 주소 환경변수를 기준으로 링크를 만들고, 공연 id를 경로에 넣는다.

### A4. 숨긴 대화방의 안 읽음 배지가 지워지지 않음 (중간)
- 걸린 해법: a007, a010, a008(배지가 목록에 없는 메시지를 센다는 지적)
- 증상: 안 읽은 메시지가 있는 채로 대화방을 숨기면 채팅 탭 배지가 계속 남고, 지울 방법이 없다.
- 고칠 방향: 배지는 보이는 대화방의 안 읽음만 세거나, 숨길 때 읽음 처리한다.

### A5. 바텀시트(Sheet) 접근성이 말과 다름 (중간)
- 걸린 해법: a005, a006, a008, a010
- 증상: 시트가 `aria-modal="true"`라고 하면서 키보드 초점을 가두지 않는다. 스크린리더 사용자가 시트 밖으로 나갈 수 있고, 닫은 뒤 초점이 되돌아오지 않는다.
- 고칠 방향: 열릴 때 첫 요소로 초점 이동, Tab 순환 가두기, 닫을 때 원래 버튼으로 복귀를 실제로 구현한다.

### A6. 자기가 세운 디자인 규칙을 같은 변경 안에서 어김 (낮음)
- 걸린 해법: a003("검은 버튼은 한 화면에 하나" 위반), a004, a008, a009("되돌릴 수 없는 동작" 규칙을 "넘기기"가 위반), a002, a005
- 증상: 문서에 새 규칙을 적었는데, 같은 변경의 매칭 화면 등이 그 규칙을 어긴다.
- 고칠 방향: 규칙을 추가할 때 모든 화면을 한 번 훑어 위반이 없는지 확인한다.

## B. 일부 해법에만 나온 기능 문제

### B1. 매칭 "넘기기"를 되돌릴 수 없음 (중간)
- 걸린 해법: a003, a001, a009
- 증상: 넘긴 사람이 영구히 저장되고 다시 꺼낼 곳이 없다. 목록이 비면 "추천할 사람이 없어요" 같은 문구가 사실과 달라진다.
- 고칠 방향: "넘긴 사람" 목록과 되돌리기를 두거나, 일정 기간 뒤 다시 추천한다.

### B2. 예매 오픈일(파란 점)을 눌렀을 때 정보가 사라짐 (중간)
- 걸린 해법: a010
- 증상: 예매 오픈일을 누르면 "이날은 공연이 없어요"가 뜨고, 그날 열리는 예매 정보는 보이지 않는다.
- 고칠 방향: 선택한 날에 공연이 없어도 예매 오픈 공연을 함께 보여 준다.

### B3. 공연 시작 시각 이후 표시가 모순됨 (낮음)
- 걸린 해법: a001, a009, a010
- 증상: 공연 당일 시작 시각이 지나면 "오늘 공연"과 "공연 종료"/"끝난 공연이에요"가 한 화면에 같이 나온다.
- 고칠 방향: 종료 판단을 공연 시작이 아니라 공연 날짜 하루가 끝난 시점(또는 종료 시각)으로 한다.

### B4. 야간 광고 동의를 끌 수 없는 사용자가 생김 (중간)
- 걸린 해법: a004
- 증상: 이미 야간 광고 동의가 저장된 사용자는 토글이 켜진 채로 잠겨서 철회할 수 없다.
- 고칠 방향: 광고성 수신 동의가 꺼져 있을 때만 야간 토글을 잠그고, 켜진 상태는 언제든 끌 수 있게 한다.

### B5. Enter 두 번으로 계정이 삭제될 수 있음 (높음)
- 걸린 해법: a006
- 증상: 새 시트의 초점 처리 때문에, 계정 삭제 확인 시트에서 Enter를 두 번 누르면 바로 삭제된다.
- 고칠 방향: 파괴적 동작의 버튼에는 초점을 기본으로 주지 않고, 취소 버튼에 초점을 둔다.

### B6. 알림을 껐는데 "예매 오픈 알림 받는 중"으로 표시됨 (중간)
- 걸린 해법: a006
- 증상: 서비스 알림을 끈 뒤에도 공연 상세에 알림 받는 중이라고 나온다.
- 고칠 방향: 표시를 실제 동의 값에서 계산한다.

### B7. 제재 안내 문구가 기획서와 모순됨 (중간)
- 걸린 해법: a009
- 증상: 동의 화면에서 고친 제재 안내 문구가 기획서 9.3의 제재 기준과 다르다.
- 고칠 방향: 문구를 기획서 9.3 원문에 맞춘다.

### B8. 공연 상세에서 온 매칭 목록의 점수 표시가 모순됨 (낮음)
- 걸린 해법: a001
- 증상: "0% 취향 일치"와 "함께 좋아하는 아티스트 1명"이 같이 나온다. A1과 같은 뿌리다.

### B9. 화면 이동 시 스크롤이 0으로 되돌아감 (낮음)
- 걸린 해법: a001
- 증상: 뒤로 가기를 하면 목록 위치를 잃는다.
- 고칠 방향: 경로별 스크롤 위치를 저장했다가 복원한다.

### B10. 기존 저장 상태와 호환되지 않음 (낮음)
- 걸린 해법: a003, a004, a009
- 증상: "저장된 상태가 그대로 열린다"고 했지만, 업데이트 후 기존 사용자는 예전 대화가 모두 안 읽음으로 보인다.
- 고칠 방향: 저장 버전을 올리고 마이그레이션에서 읽음 처리를 채운다.

## C. 접근성·터치·계층 문제

### C1. 캘린더 날짜 접근성 (중간)
- 걸린 해법: a003, a005, a007, a002
- 증상: 날짜 터치 영역이 오히려 줄거나, FullCalendar의 `<a>` 안에 버튼을 넣어 Tab 정거장이 30개 이상 생기고, 스크린리더 이름표가 날짜를 가릴 수 있다.
- 고칠 방향: 날짜 칸 하나를 버튼 하나로 만들고, 이름표에 "11월 12일, 공연 2건" 형태로 날짜를 넣는다. 전체를 화살표 키로 이동하게 한다.

### C2. 터치 영역 44px 미달 (중간)
- 걸린 해법: a005(PillSelect), a002(지역 필터)
- 증상: 44px 규칙을 문서에 적고도, 새로 만든 알약 선택/필터가 그보다 작거나 일부만 눌린다.

### C3. 새로 추가한 글자색이 대비 기준 미달 (낮음)
- 걸린 해법: a001(azure 글자), a010("알겠어요" 버튼), a006(대비 미달을 알면서 체크 완료로 표시)
- 증상: 기준으로 삼은 4.5:1에 못 미친다.
- 고칠 방향: 대비를 실제로 계산해 확인한다. 어두운 배경 위 흰 글자는 통과하지만, 밝은 파란색 글자는 흰 배경에서 미달일 수 있다.

### C4. 채팅 숨기기가 모바일 스크린리더에서 막힘 (중간)
- 걸린 해법: a002
- 증상: 숨기기를 스와이프에 의존하는데, 스크린리더 사용자는 쓸 수 없다. 해법은 고쳤다고 했지만 실제로는 대체 경로가 막혀 있다.
- 고칠 방향: 오른쪽 `…` 버튼이나 행 동작 메뉴 같은 대체 경로를 항상 둔다.

### C5. 컴포넌트 계층 위반 (낮음)
- 걸린 해법: a007
- 증상: 조합 부품이 목업 데이터를 직접 읽고, 화면 안에서 부품을 새로 정의한다. 기획서 13장의 계층(토큰 → 기본 부품 → 조합 부품 → 화면)에 어긋난다.

### C6. 기타 (낮음)
- "오늘" 버튼이 데모 시간(`timeOffset`)이 아니라 실제 시계 기준 달로 이동한다. (a006, a009)
- "7일" 쉬는 기간이 만료·거절 요청에서는 실제로 약 4일이다. (a008)
- 예매 오픈 전 안내 문구가 근거 없는 사실을 단정한다. (a001)
- 필터 초기화가 아무것도 바꾸지 않거나 범위 선택까지 지운다. (a002)
- 변경사항 보호(저장 전 이탈 방지)가 화면의 뒤로 가기 버튼에만 적용된다. (a005)
- 기획서 5.3의 "거절·만료 상대 재추천 제외" 규칙을 건너뛴다. (a004)
