# 덕친소 디자인 기획안 v1

작성일: 2026-10-31 · 적용 위치: `src/styles/index.css`(토큰), `src/components`(부품)

## 방향

화이트 바탕, 블랙 텍스트, Apple의 iOS 기본 앱과 apple.com의 절제된 화면을 기준으로 삼는다. 장식은 빼고 여백·글자 크기·얇은 구분선으로 위계를 만든다.

화면 전체는 조용하게 두고, 강조는 한 곳에만 쓴다. **공연 상세를 Apple Wallet의 입장권(패스)처럼 만든 검은 티켓**이 그 한 곳이다. 공연 앱에서 사용자가 결국 원하는 것이 티켓이라는 점을 그대로 형태로 옮겼다.

## 색

| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| Paper | `#FFFFFF` | 기본 바탕 |
| Mist | `#F5F5F7` | 입력창·세그먼트·검색창 같은 조작 영역 바탕 |
| Ink | `#1D1D1F` | 본문 텍스트, 주요 버튼, 선택된 날짜, 티켓 |
| Graphite | `#6E6E73` | 보조 텍스트 |
| Hairline | `#D2D2D7` | 구분선 |
| Rose | `#E5245E` | 공연일 점, 관심 표시, 배지 (강조색은 이것 하나) |
| Azure | `#0071E3` | 예매 오픈일 점, 텍스트 링크 |

- 주요 버튼은 강조색이 아니라 **Ink(검정)** 로 칠한다. apple.com의 구매 버튼처럼 색 대신 명도 대비로 누를 곳을 보여 준다.
- 위험 동작(차단·나가기·삭제)은 iOS처럼 빨간 글자(`#D70015`)만 쓰고 바탕은 칠하지 않는다.
- 다크 모드는 이번 버전에서 제외(화이트 바탕 지정). 토큰 구조는 유지해 나중에 추가한다.

## 글꼴

- **Pretendard Variable** 한 가족만 쓴다. 한글·영문·숫자의 굵기와 폭이 SF Pro와 가장 비슷하다.
- 숫자는 고정폭 숫자(`tabular-nums`)로 날짜·시각이 세로로 맞도록 한다.

| 역할 | 크기/행간 | 굵기 | 자간 |
| --- | --- | --- | --- |
| 큰 제목 (탭 첫 화면) | 32/38 | 700 | -0.025em |
| 제목 | 22/28 | 700 | -0.02em |
| 소제목·목록 제목 | 17/22 | 600 | -0.01em |
| 본문 | 15/22 | 400 | 0 |
| 보조 | 13/18 | 400 | 0 |
| 캡션 | 11/14 | 500 | 0 |
| 날짜 숫자(목록) | 28/28 | 300 | -0.03em |

## 레이아웃

탭 첫 화면은 iOS처럼 **큰 제목을 왼쪽 정렬**로 두고, 아래로 내려가면 얇은 상단 바만 남는다. 모든 텍스트는 왼쪽 정렬.

```
캘린더(홈)                         공연 상세
┌───────────────────────┐        ┌───────────────────────┐
│ 공연 캘린더             │        │ ‹ 캘린더               │
│ 2026년 11월      ‹  ›  │        │ ┌───────────────────┐ │
│ 일 월 화 수 목 금 토    │        │ │ 요아소비           │ │
│  1  2  3  4  5  6  7   │        │ │ YOASOBI ASIA TOUR │ │
│        •     •         │        │ │                   │ │
│ (선택일 = 검은 원)       │        │ │ 공연 일시  예매 오픈│ │
├───────────────────────┤        │ │ 11월 14일  10월 20일│ │
│ [관심 | 전체] 세그먼트  │        │ │ 장소               │ │
│ 14  YOASOBI ASIA TOUR  │        │ ├ ─ ─ ─ ─ ─ ─ ─ ─ ─┤ │ ← 절취선
│ 토  KSPO DOME 18:00    │        │ │ 예매처  NOL 티켓   │ │
│ ───────────────────── │        │ └───────────────────┘ │
│ 15  ...                │        │ [ NOL 티켓에서 예매 ]   │
├───────────────────────┤        │ 카카오맵 · 구글맵 길찾기 │
│ 캘린더 매칭 채팅 내정보  │        └───────────────────────┘
└───────────────────────┘
```

- 목록은 카드 대신 **얇은 구분선으로 나뉜 행**(iOS 목록). 구분선은 아이콘·숫자 다음부터 시작한다.
- 캘린더는 칸 테두리 없이 숫자와 점만 둔다(iOS 캘린더 월 보기). 공연일은 Rose 점, 예매 오픈일은 Azure 점.
- 탭바는 반투명 흰색 + 흐림 효과, 선택된 탭은 Ink.
- 확인 창은 iOS 액션 시트(둥근 흰 버튼 묶음 + 분리된 취소 버튼).

## 원칙

1. 강조는 티켓 하나. 나머지 화면에는 그림자·그라데이션을 쓰지 않는다.
2. 상태는 색보다 글자로 먼저 말한다(예: "예매 오픈 예정").
3. 터치 영역은 44px 이상, 키보드 초점은 검은 테두리로 보인다.
4. 움직임은 사용자 동작에 대한 응답(시트 올라오기, 행 밀기)에만 쓴다. 동작 줄이기 설정을 따른다.
