## 방향

토스와 애플처럼 차분하게 만든다. 대표색은 블랙·화이트이고, 원색은 쓰지 않는다. 바탕은 화이트, 글자는 블랙이며, 다크 테마를 함께 제공한다.

장식 대신 여백·글자 크기·얇은 구분선으로 위계를 만든다. **상자는 꼭 필요한 곳에만 쓴다.** 작은 글자나 글자 버튼은 바탕 없이 그대로 둔다(글자 버튼, 밑줄 탭, 밑줄 입력창).

## 테마

MY > 설정 > 테마에서 기기 설정 / 라이트 / 다크를 고른다. 기본값은 기기 설정이다. 토큰만 바꾸므로 화면 코드는 그대로다.

## 아이콘

기본 아이콘 세트를 쓰지 않고, 기능을 요약한 자체 아이콘 34개를 그렸다(24px, 1.7px 선). 아이콘 하나가 함수 하나라서 따로 고칠 수 있다.

| 아이콘 | 모양에 담은 뜻 |
| --- | --- |
| 공연·캘린더 | 달력 한 장 + 오른쪽 티켓 절취 홈 |
| 커뮤니티 | 겹친 두 말풍선 |
| 채팅 | 말풍선 + 주고받는 두 점 |
| MY | 프로필 카드 |
| 관심 공연 | 티켓 모양 책갈피 (담으면 채워짐) |
| 추천(글) | 위로 올리는 화살표 |
| 친구 요청함 | 사람 + 들어오는 화살표 |
| 채팅 없음 | 말풍선에 사선 |
| 표시 방식 전환 | 점·선 모양 / 이름 줄 모양 |

## 캘린더 표시 규칙

- **하루 공연:** 날짜 아래 작은 점. 같은 날 여러 공연이면 점 여러 개, 공연마다 다른 색
- **같은 투어의 연속 공연(2일 이상):** 날짜를 잇는 선
- **떨어져 있는 투어 날짜:** 그날만 짧은 선(점과 구분)
- 선은 공연마다 같은 줄(높이)에 오도록 배치해서 칸이 바뀌어도 이어져 보인다. 주가 바뀌는 곳에서는 끊는다.
- **이름 모드:** 오른쪽 위 버튼으로 바꾼다. 날짜 칸에 아티스트 이름을 최대 2개 보이고, 넘치면 +n
- **관심 공연 날짜:** 숫자에 진한 테두리
- **선택한 날짜:** 검은 원
- **오늘:** 숫자 아래 짧은 밑줄

## 부품 분리와 묶음 근거

기본 원칙: 모든 개체를 분리한다. 토큰 → 기본 부품 → 조합 부품 → 화면 순서이고, 파일 하나에 부품 하나다.

- **기본 부품:** Button, Avatar, Badge, Confirm, Sheet, Toast, Toggle, Checkbox, Segmented, TextTabs, TextField·TextArea, Empty
- **조합 부품:** AppHeader, BottomNav, MonthCalendar, ConcertRow, Poster, UserRow, PostRow, PickList, ConsentList, ReportSheet, MenuRow, ImageButton

불가피하게 묶은 곳과 그 근거:

| 묶은 곳 | 근거 (기획서 13장 기준) |
| --- | --- |
| `MonthCalendar`의 날짜 칸(숫자·점·선·이름) | 한 달에 35~42칸이 반복 렌더링된다. 칸 안을 더 쪼개면 칸마다 부품 수가 4배가 되고, 점·선 위치가 같은 배치 계산(`layoutMarks`)에 묶여 있어 따로 고칠 일이 없다. 모양 값(색·두께)은 `lib/calendar.ts`의 상수로 분리했다. |
| `ChatRoom`의 말풍선(`Bubble`) | 채팅방 한 화면에서만 쓰고 상태가 없는 작은 조각이다. 다른 화면에서 쓰게 되면 `components`로 옮긴다. |
| `Search`의 범주 칩(`Chip`) | 검색 화면 전용의 상태 없는 조각이다. |
| `ConcertDetail`의 정보 줄(`Info`) | 공연 상세 전용의 배치 조각이다. |

## 원칙

1. 누를 곳은 하나만 진하게(검은 바탕 버튼). 나머지는 글자 버튼이나 옅은 바탕을 쓴다.
2. 상태는 색보다 글자로 먼저 말한다(예: "예매 중", "오픈 예정").
3. 터치 영역은 44px 이상, 키보드 초점은 진한 테두리.
4. 위험 동작의 확인 창은 초점을 "취소"에 둔다(Enter 연타로 삭제되는 문제 방지, 검토 문제점 B5).
5. 움직임은 사용자 동작에 대한 응답(시트, 확인 창)에만 쓰고, 동작 줄이기 설정을 따른다.

## 1차 수정 (2026-11-04)

- 설명 문구를 줄였다. 법적 고지(KOPIS 출처), 위험 동작 경고, 빈 화면의 다음 행동만 남겼다.
- 바텀시트: 취소 버튼을 시트 안 맨 아래에 붙였다. 열릴 때 뒤 화면이 흔들리지 않게 했다(초점 이동 시 스크롤 금지).
- 화면 전환: 모든 화면(로그인 화면 포함)이 쓸려 들어온다(320ms). 다음 화면·오른쪽 탭은 오른쪽에서, 뒤로 가기·왼쪽 탭은 왼쪽에서. 탭끼리 옮길 때 하단 바는 고정. 모바일에서는 좌우로 밀어 이전·다음 탭으로 간다. 가로로 스크롤되는 영역 안에서 민 것은 무시한다.
- 테마 전환: 바꾸는 동안 0.45초에 걸쳐 색이 바뀐다. 동작 줄이기 설정이면 바로 바뀐다.
- 시뮬레이션 기준 화면: 390×844. 반응형 레이아웃은 이후 적용한다.

## 2차 수정 (2026-11-04)

- 회원 로그인: 이메일·비밀번호 입력란을 화면 가운데에 두고, 바로 아래에 "이메일로 가입 | 로그인" 글자 버튼. 간편 로그인 버튼은 아래쪽.
- 아이콘: 추천 = 엄지 척(추천하면 채워짐), 설정 = 톱니 8개 톱니바퀴, 문의 = 더 큰 말풍선 + 굵은 물음표, 캘린더 이름 모드 = 달력 칸에 이름 띠(곧은 선만, "내 정보" 아이콘과 구분되게 달력 머리줄 포함).
- 소개글 입력란 안내 문구: "당신의 덕력을 뽐내보세요!" (입력하면 사라짐)
- 채팅방 진입 시 튕김 수정: 맨 아래로 내릴 때 목록 안에서만 스크롤한다.
- 회원 로그인 실패: 입력란 밑줄이 1.4초 동안 붉게 바뀌고 좌우로 짧게 흔들린다. 비밀번호 아래에 붉은 글씨로 "아이디 또는 비밀번호가 올바르지 않습니다"가 나오고, 다시 입력하면 사라진다.
- "아이디/비밀번호 찾기" 버튼을 로그인 옆에 두었다. 기능은 본인인증(보안 기획서 7장)과 함께 구현한다. 그 전까지는 준비 중 안내만 띄운다.
