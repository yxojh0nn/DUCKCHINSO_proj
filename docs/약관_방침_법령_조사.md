# 약관·방침·환불·쿠키·위치·앱 권한 법령 조사

조사 2026-11-19 · 반영: `src/data/legal.ts`(개인정보처리방침·이용약관·쿠키 정책), `src/data/business.ts`(환불 정책), 앱 권한 안내·활동 지역 기능
**2차 자료(로펌 칼럼·해설)를 포함한 조사다. 출시 전 국가법령정보센터 원문과 법률 검토로 확인할 것.**

## 1. 개인정보처리방침 (개인정보 보호법 30조, 시행령 31조, 2025-04 작성지침)

필수 기재 (해당 시 포함): 처리 목적, 처리·보유 기간, 제3자 제공, 파기 절차·방법, 민감정보 공개 가능성, 처리 위탁, 가명정보, 정보주체 권리·행사 방법, 개인정보 보호책임자, **쿠키 등 자동 수집 장치의 설치·운영·거부**, 처리 항목, **국외 이전(28조의8)**, 안전성 확보 조치, 국내대리인.

2025 작성지침 개정: 동의 없이 처리하는 항목(계약 이행 등)과 동의가 필요한 항목을 나눠 적기, 14세 미만 아동 처리는 해당 시 필수, 권리 행사에 전송요구·자동화된 결정 안내 추가. 작성지침 자체는 권고, 위반 판단은 법 30조·시행령 기준.

반영: 근거 구분 문단, 법정 보관(전자상거래법 5년/3년/6개월, 통신비밀보호법 3개월), 위탁(Supabase·Vercel·Resend·Cloudflare·포트원), 국외 이전 표(이전받는 자 연락처·국가·항목·목적·보유기간·거부 방법), 덕친 추천 기준 공개, 구제기관 연락처.

확인할 것: KLIPY 의 법인명·서버 소재국·연락처 (공식 자료를 찾지 못함), 포트원 운영사 법인명.

## 2. 이용약관 (약관규제법, 공정위 시정 사례)

- 포괄적 면책 조항, 고의·과실과 무관한 책임 제한은 무효 사례가 많다 → 제13조를 "고의·과실이 있으면 책임" 구조로.
- 이용 제한 사유가 포괄적·자의적이면 무효 → 제8·10조에 구체 사유, 통지·이의 절차.
- 묵시적 동의 간주(거부하지 않으면 동의)는 시정 대상 → 제3조에서 배제.
- 관할은 회사 소재지 전속으로 두지 않고 민사소송법에 따른 관할.

## 3. 환불·정기결제 (전자상거래법)

- 17조: 계약 내용 받은 날부터 7일 안 청약철회. 디지털 콘텐츠 제한은 미리 알리고 시험 사용 조치를 한 경우에만 → 덕친소는 제한하지 않고 7일 전액 환불.
- 18조: 철회 시 3영업일 안 환급, 늦으면 지연배상금 (2차 자료 확인, 원문 대조 필요).
- 2025-02-14 시행 개정: 정기결제 증액·유료 전환 시 사전 동의(증액 30일 전으로 알려짐, 유료 전환 기간은 자료마다 14일/30일로 엇갈림 → 약관은 둘 다 30일로 보수적으로), 해지 방해(다크패턴) 금지.
- 미성년자 법정대리인 동의 없는 결제 취소(민법 5조) 명시.

## 4. 쿠키와 동의 배너

- 국내법은 쿠키에 GDPR 같은 사전 동의(opt-in) 배너를 명시적으로 요구하지 않고, 처리방침에 설치·운영·거부 방법 공개를 요구한다 (법 30조 1항 7호). 공신력 있는 자료로 "배너 불필요"를 직접 확인하지는 못했다.
- 덕친소는 광고·분석 쿠키가 없고 꼭 필요한 브라우저 저장소만 쓴다 → 배너 없이 `/legal/cookies`로 공개. 광고·분석 도구를 넣으면 그 전에 동의 배너를 만든다.

## 5. 위치 (위치정보법)

- 위치기반서비스사업 신고 대상은 개인위치정보를 대상으로 하는 사업. 위치정보센터 안내: 개인위치정보를 **단말기에서만 활용하고 사업자의 위치정보시스템으로 전송하지 않으면 신고 대상에서 제외**.
- 주소(거주지)는 위치정보가 아니라 개인정보로 본다는 해설이 있다.
- 설계: "현재 위치로"는 기기 안에서 가장 가까운 시·도를 고르고 좌표는 버린다. 서버에는 사람이 확인한 시·도 이름만 저장 (`profiles.region`, 마이그 45). 좌표를 서버로 보내는 기능(근처 사람 거리 표시 등)을 만들면 신고·위치 약관·별도 동의가 필요해진다.

## 6. 앱 접근 권한 (정보통신망법 22조의2, 시행령 9조의2)

- 필수/선택 권한을 나눠 항목과 이유를 알리고 동의를 받는다. 선택 권한은 거부할 수 있음을 알리고, 거부를 이유로 서비스를 막으면 안 된다. 선택 권한은 그 기능에 처음 접근할 때 묻는다. 위반 시 과태료.
- 반영: 앱 첫 실행 때 접근 권한 안내(`PermissionNotice`), MY › 설정 › 앱 접근 권한(`Permissions`), 필수 권한 없음, 카메라·대략적 위치·사진 저장(iOS) 모두 선택.
