# 덕친소 (가칭)

J-pop 공연 일정을 캘린더에 모아 보고, 좋아하는 아티스트가 겹치는 사람과 상호 수락으로 대화할 수 있는 앱입니다. 웹(React + Vite)으로 만들고 Capacitor로 Android·iOS에 배포합니다.

## 웹 프로토타입 실행

Supabase 연결 전이라 목업 데이터와 브라우저 저장소(localStorage)로 동작합니다. 공연 정보는 샘플이며 실제 공연이 아닙니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 http://localhost:5173 을 엽니다. 데스크톱에서는 휴대폰 폭으로 가운데 표시됩니다. 처음 상태로 돌리려면 내 정보 › 계정 삭제를 누릅니다.

| 화면 | 확인할 수 있는 것 |
| --- | --- |
| 동의 | 필수 4개·선택 3개, 전체 동의, 계정 제재 고지 |
| 아티스트 지정 | 최대 5명, 검색, 나중에 하기 |
| 캘린더(홈) | 상단 월간 캘린더(공연일·예매 오픈일), 날짜별 목록, 관심/전체 필터 |
| 공연 상세 | 일시·예매 오픈·장소·예매처, 카카오맵·구글맵 길찾기, 예매처 새 탭 |
| 매칭 | 겹치는 아티스트 순 추천, 하루 2회 요청 한도, 받은 요청 수락·거절, 3일 만료 |
| 채팅 | 메시지(자동 답장), 신고·차단·나가기, 상대 퇴장 안내, 밀어서·길게 눌러 숨기기 |
| 내 정보 | 시·도 지역, 내 정보 비공개, 차단 해제, 데모 도구(요청 받기·하루 지나기·상대 퇴장) |

코드 구조는 기획서 13장의 계층을 따릅니다: `src/styles`(토큰) → `src/components/ui`(기본 부품) → `src/components`(조합 부품) → `src/screens`(화면).

## 작업 규칙 (요약)

- main에 직접 푸시하지 않고, 작업 브랜치(`feat/` `fix/` `chore/` `docs/`) → PR → Squash merge
- 패키지 매니저는 pnpm만 사용 (`pnpm-lock.yaml`만 커밋)
- 비밀키는 커밋하지 않음 (`.env.example`에 이름만)
